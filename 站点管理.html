      怎么用 / 字段说明
      

        
    
          
  1. 改完站点和配置项后，右侧 index.html 就是 App 要读的配置（文件内容就是纯 JSON，不是网页）；「下载」后直接覆盖 合集/index.html 即可，静态空间也能托管。
    2. 
          
  2. 要在本地自检台 server.js 里测到这站，把 server.js 标签里的片段粘进 SITES 数组。
    3. 
          
  3. 浏览器不能直接写文件，所以给的都是「复制 / 下载」；粘贴回编辑器保存即可。
    4. 
          
  4. 旧的 vod.php / site.txt 导入仍然可用（只在迁移时用得到）。
    5. 
        

        
站点字段：

        
    
          
  • key*：唯一标识，字母/数字/下划线/短横线；也作为 server.js 的环境变量前缀。
    • 
          
  • 名称*：App 里显示的名字。
    • 
          
  • 类型：JSON 里的 type，纯 JS 脚本站固定 3。
    • 
          
  • 脚本文件：生成 api: "./js/文件名"；和 api 字段二选一，都空就报错。
    • 
          
  • api / jar：手填完整 api（如 csp_xxx）或 jar 地址，给非本站脚本的源用。
    • 
          
  • 域名：写进 ext.api；换镜像时只改这里。
    • 
          
  • 超时：秒，5～120；聚合站类偏慢的给 30。
    • 
          
  • 可搜索 / 快速搜索 / 可筛选 / 可切换：对应 JSON 的 searchable / quickSearch / filterable / changeable，默认 1/1/0/1。
    • 
          
  • 搜索关键词、环境变量、源目录、备注：只给 server.js 自检和注释用，不进配置 JSON。
    • 
          
  • 启用：取消勾选后不进 index.html，也不进 server.js。
    • 
        

        
配置段（lives / parses / rules / doh / hosts / ijk / ads）：直接是 JSON 数组文本，改完自动校验；格式错了不写进文件，按提示修。只有 name 是必填项，其余字段都可以不写。
